Pass Alarm - Є Термін!

Pass Alarm ist eine Android-App, die die öffentlich zugänglichen Seiten der elektronischen Warteschlange des Passport-Service (pasport.org.ua) überwacht und sofort ein lautes Signal auslöst, wenn freie Termintage erscheinen — für alle Städte, die die App unterstützt. Manuelles Nachladen der Warteschlangenseite gehört damit der Vergangenheit an.

Pass Alarm — застосунок для Android, який стежить за публічними сторінками електронної черги паспортного сервісу (pasport.org.ua) і одразу подає гучний сигнал, коли з'являються вільні дні для запису — для всіх міст, які підтримує застосунок. Вручну оновлювати сторінку черги більше не потрібно.
